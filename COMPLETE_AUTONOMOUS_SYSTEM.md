## 🚀 Usage Examples

### Fully Autonomous Mode
```typescript
import { AutonomousSystem } from './src/synth/autonomous';

// Initialize and start
const system = new AutonomousSystem();
system.start();

// System now runs autonomously:
// - Monitors conversations
// - Detects gaps
// - Researches online
// - Generates training data
// - Trains model
// - Deploys updates
// - Monitors performance
// - Repeats forever!

// Check status anytime
console.log(system.getStatusReport());
```

### Manual Control
```typescript
// Force an update on specific topic
await system.forceUpdate('machine learning');

// Check knowledge gaps
const gaps = system.getGapDetector().getCriticalGaps();
console.log(`Found ${gaps.length} critical gaps`);

// Research a topic
const research = await system.getWebIntegration().research('quantum computing');
console.log(`Found ${research.searchResults.length} sources`);

// Generate training data
const examples = system.getTrainingAutomation().generateFromResearch(research);
console.log(`Generated ${examples.length} examples`);

// Rollback if needed
system.rollback();
```
